# ZenNotes

> A sleek, responsive note-taking application built with React.js, Redux Toolkit, and Tailwind CSS to practice state management with Redux Toolkit.

## Key Features

- **Rich Note Creation:** Add notes complete with titles, rich content, and customizable tags.
- **Full CRUD Support:** Easily edit, update, or delete existing notes.
- **Favorites & Search:** Mark important notes as favorites and quickly filter through notes by title.
- **Flexible Sorting:** Sort your collection by newest, oldest, or alphabetically (A–Z / Z–A).
- **Multiple Layout Views:** Toggle seamlessly between a Grid view and a List view.
- **Customization & UI Settings:**
  - Dark / Light theme switcher
  - Custom accent color selection
  - Dynamic font selection

## Tech Stack

- **Frontend:** React.js
- **State Management:** Redux Toolkit
- **Styling:** Tailwind CSS
